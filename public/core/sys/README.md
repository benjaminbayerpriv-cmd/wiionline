# Dolphin replacement fonts

Unmodified font_western.bin, font_japanese.bin and font-licenses.txt from Dolphin commit e22551eae1c84a7e4d0b6a5c519ef4ed4ef69df1, Data/Sys/GC.
Source: https://github.com/dolphin-emu/dolphin/tree/e22551eae1c84a7e4d0b6a5c519ef4ed4ef69df1/Data/Sys/GC

These are Dolphin's generated replacement fonts based on Google Droid Sans, Apache License 2.0. The complete upstream attribution and license are preserved in GC/font-licenses.txt. They are loaded into /dolphin-sys/GC in the virtual filesystem before native runtime initialization. No console firmware is bundled.
